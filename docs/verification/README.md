# Release verification / Проверки релиза

[Home](../../README.md) · [Главная](../../README.ru.md)

The release was prepared on Windows 11 x64 with Python 3.12.7, PySide6 Essentials 6.12.0, PyInstaller 6.22.3 and Unicorn 2.1.4. Dependencies were installed in a new virtual environment from the committed requirements files.

Релиз подготовлен в Windows 11 x64: Python 3.12.7, PySide6 Essentials 6.12.0, PyInstaller 6.22.3, Unicorn 2.1.4. Зависимости установлены в новое виртуальное окружение из списков репозитория.

| Check / Проверка | Evidence / Результат |
|---|---|
| Logic and native adapter suite / Тесты логики и адаптера | [unit-tests.json](unit-tests.json) |
| Bundled EXE UI and native modules / Интерфейс EXE и нативные модули | [self-test.json](self-test.json) |
| Runtime assets, checksums and local links / Ресурсы, суммы и ссылки | [repository-check.txt](repository-check.txt) |

The self-test uses protocol fixtures and native mock processes. It opens no game capture. Live-client experiments are documented separately in the historical technical notes.

Встроенная проверка использует примеры протокола и нативные тестовые процессы без захвата игры. Опыты с живым клиентом описаны отдельно в исторических технических материалах.

The packaged application starts and its native modules load. The current-session native self-test stops when `SetWindowsHookExW` returns Win32 error 126 at the `install-hook` stage. The same operation succeeds for previously registered module images and fails for newly copied images in this session. A session hook-module resource limit is a working hypothesis, not a confirmed diagnosis. The exact failed check is retained in `self-test.json`; the earlier complete 376-test result is recorded separately.

# Иконки предметов, скиллов и бафов

Оригинальные изображения извлечены из локальных пакетов `SysTextures/Icon.utx`,
`BranchSys.utx`, `branchsys2.utx` и `br_cashtex.utx`. Привязки к ID взяты из
`asterios/Skillgrp.dat`, `EtcItemgrp.dat`, `Armorgrp.dat` и `Weapongrp.dat`;
набор ID предметов дополнительно сверяется с `AdditionalItemGrp.dat`.
Игровые файлы не изменяются, запуск игры для извлечения не требуется.

Архив `assets/client-icons.zip` содержит 4 751 уникальное изображение PNG,
привязки для 19 100 ID предметов и 65 752 пар ID/уровень скиллов и бафов.
Для 8 014 ID скиллов доступна общая иконка, одинаковая на всех известных
уровнях. Дополнительная короткая ссылка на текстуру используется только
при уникальном имени внутри пакета; при совпадении разных картинок выбор
не угадывается.

Иконки отображаются в инвентаре, предметах рядом, справочнике ID,
списках скиллов и активных бафов, базе клиента и выборе хилки. Размер
отображения — 32×32. Изображения загружаются по мере прокрутки;
кэш ограничен 512 изображениями. Архив включён в самостоятельный EXE.

Полная база названий содержит больше записей, чем стандартные таблицы
иконок этого клиента. Для отсутствующей привязки или текстуры остаётся
название без картинки. При извлечении обнаружено 76 отсутствующих ссылок
на текстуры; ошибок декодирования найденных текстур нет. Названия и ID
сохраняются независимо от наличия картинки.

Повторное извлечение: `python packaging/build_client_icons.py`.
Сборка EXE: `python packaging/build.py --dist-dir dist-update-itemlist`.
Подробный отчёт с контрольными суммами исходных файлов:
extraction.json (`reports/client-icons/extraction.json`).

Проверки охватывают реальные картинки хилки и Wind Walk, общий значок
Newbie Buff, отсутствующие ID, отсутствие архива и вытеснение из кэша.
Самопроверка окна дополнительно проверяет загрузку изображений инвентаря,
скиллов, бафов и выбора хилки; она запускается и для собранного EXE.
Все проверки выполняются без игры и сетевой отправки.

Для чтения стандартных форматов использованы первичные описания кода:
[L2crypt, RSA framing](https://github.com/acmi/L2crypt/blob/master/src/main/java/acmi/l2/clientmod/crypt/rsa/L2Ver41xInputStream.java),
[L2FileEdit, H5 DAT schemas](https://github.com/ellysh/L2FileEdit/tree/master/data/l2asm-disasm/DAT_defs/H5),
[UEViewer, Unreal texture serialization](https://github.com/gildor2/UEViewer/blob/master/Unreal/UnrealMaterial/UnTexture2.cpp).
Лицензия L2crypt сохранена в [third_party/LICENSE-L2crypt.txt](../third_party/LICENSE-L2crypt.txt).

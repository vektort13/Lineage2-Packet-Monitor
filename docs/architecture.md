# Архитектура — заготовка этапа 2

Подтверждённая схема конкретного сервера пока отсутствует. На этапе 2 нужно выбрать доступную реализацию, зафиксировать commit и сослаться на конкретные классы и строки KnownList/WorldRegion, регистрации объектов, broadcast и формирования CharInfo/UserInfo/DeleteObject.

Рабочая модель будущего анализатора:

```text
События собственного сервера ─┐
                             ├─> проверка JSONL ─> временная шкала ─> сравнение ─> отчёт
Наблюдения тестовых клиентов ─┘
```

Это проектная схема инструмента. Она не описывает доказанное устройство NCSoft или Asterios. Архитектурные сведения о сервере будут добавлены после проверки исходников; гипотезы из задания сами по себе не являются источниками.

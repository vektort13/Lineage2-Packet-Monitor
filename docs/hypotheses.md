# Гипотезы — заготовка

H1–H6 перенесены из задания пользователя как направления проверки. Ни одна пока не подтверждена.

| Гипотеза | Что необходимо сопоставить |
|---|---|
| H1: отрисовка клиента | Положительное состояние сервера, доставку/обработку появления и фактическую видимость |
| H2: KnownList | Списки известных объектов и независимо ожидаемый интерес для направленных пар |
| H3: жизненный цикл | Создание, регистрацию, удаление, повторное появление и идентичность объекта |
| H4: позиция/состояние | Позиции, регионы и состояния сервера и клиентов в одном интервале |
| H5: порядок событий | Порядковые номера, отправку и обработку появления/удаления |
| H6: сочетание клиента и сервера | Временную последовательность локального действия и серверных переходов |

Операционные признаки, контрольные условия и критерии опровержения предстоит определить на этапе 2 после проверки конкретной реализации. Одного скриншота или серверной отправки недостаточно для установления причины.

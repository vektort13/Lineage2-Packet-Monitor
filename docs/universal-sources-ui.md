# Источники пакетов в одном окне

Девятая вкладка «Источники» объединяет выбор источника, сохранённые профили
клиентов и управление серверным мостом. Прежние восемь вкладок сохраняют
индексы и назначение.

Режимы:

- «Авто» выбирает проверенный адаптер открытых пакетов клиента, затем
  сетевой профиль. Для неизвестной сборки остаётся захват TCP без расшифровки.
- «Сетевой захват» использует профиль клиента и текущее состояние соединения.
- «Открытые пакеты клиента» требует отдельного проверенного адаптера сборки.
  Его отсутствие отображается явно.
- «Серверный мост» принимает открытые пакеты от серверного модуля. Протокол
  сообщает модуль; активный протокол виден рядом с источником.

Источник выбирается перед запуском захвата. Его можно поменять после
остановки. Выбор сохраняется в QSettings `capture/source`; явный параметр
`source` конструктора окна имеет приоритет при запуске.

Таблица профилей показывает ID, полный SHA-256 Engine.dll, алгоритм,
результат проверки, наличие адаптера клиента и протокол. Редактировать
профиль через таблицу нельзя. Кнопки импорта и экспорта используют ZIP;
импорт доступен после остановки захвата. Хранение, проверку и объединение
профилей выполняет Monitor.

У моста есть запуск, остановка, экспорт серверного модуля и копирование
конфигурации. Обычный статус показывает адрес, число принятых и пропущенных
пакетов и число сеансов. Секрет конфигурации передаётся в буфер обмена только
по явному нажатию «Копировать конфигурацию».

Интеграция окна с Monitor:

- `start(..., source=...)`, `configure_source(mode)`, `source_status()`;
- `bridge_start()`, `bridge_stop()`, `bridge_configuration()`;
- `export_bridge_package(path)`, `export_profiles(path)`, `import_profiles(path)`.

`source_status()` содержит `mode`, `active_source`, `message`,
`client_tap_supported`, `profiles`, `algorithms`, `protocol` и `bridge`.
У профиля используются `id`, `engine_sha256`, `algorithm`, `validation`,
`client_tap_supported` и `protocol`. У моста используются `running`,
`endpoint`, `received`, `dropped`, `sessions` и `active_session`.
Протокол из `active_session.protocol` имеет приоритет при показе моста.

Все новые элементы имеют русский и английский тексты и используют обе
существующие темы. Нативный self-test дополнен снимками девятой вкладки,
проверкой режимов, отображения профиля и протокола, отсутствия секрета в
статусе и отсутствия запуска моста во время проверки. Он не обращается к игре
ради проверки новых элементов.

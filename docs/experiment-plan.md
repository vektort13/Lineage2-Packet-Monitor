# План лаборатории — заготовка

Полноценные эксперименты относятся к этапу 5. Сейчас доступен клиент Asterios, но подходящий собственный сервер в рабочей папке не найден.

Первый прогон будет воспроизводить синтетические события без игрового процесса. Затем на собственном сервере нужно настроить персонажей A/B/C, зафиксировать сборки и синхронизацию времени, собирать события по направленным парам и записывать независимые наблюдения видимости, выбора цели и взаимодействия.

Контрольные сценарии из задания: обычное движение, переход региона, телепортация, повторный вход, штатное изменение видимости. Для каждого нужны ожидаемое состояние, источники наблюдений, границы временной погрешности и критерий завершения перехода.

Симуляции рассогласования выполняются при воспроизведении событий либо на собственном сервере. Проверка штатного входа в предоставленный пользователем аккаунт Asterios не считается экспериментом с рассинхронизацией.

# Результаты первичного осмотра

Осмотр 2026-11-21, Asia/Dubai. Область проверки — рабочая папка игры, PATH, выбранные стандартные пути программ, записи установки и имена процессов. Это не поиск серверов по всем дискам.

## Подтверждено локально

1. До создания проекта в папке игры было 2340 файлов, суммарно около 14.88 GiB. Присутствуют каталоги ресурсов `Animations`, `MAPS`, `StaticMeshes`, `SysTextures`, `Textures`, `Sounds`, `music`, `Video`, `Voice` и `asterios`.
2. В Asterios.ini (`../../Asterios.ini`), строка 3: `Version=Lineage II - GOD Hybrid [2015.11.07]`. Это маркировка конфигурации, а не доказательство версии сетевого протокола.
3. Asterios.exe (`../../Asterios.exe`) имеет метаданные `DRiN's Auto-Update Engine`, версия 2.5.0.0. В asterios (`../../asterios`) присутствуют `AsteriosGame.exe`, `Engine.dll`, `Core.dll`, `Interface.u`, `Engine.u` и таблицы `.dat`. Наличие файлов не устанавливает механизм аномалии видимости.
4. Исходники `.java`, `.py`, `.cs`, проекты `.sln`/`.csproj`, архивы `.jar`, `.sql` и основные манифесты серверной сборки в рабочей папке при первичном поиске не найдены.
5. `AsteriosGame.log` и `CheckGrp.log` существуют, каждый размером 246 байт. При выборочной текстовой проверке строки версии и протокола не найдены. Содержимое не использовано как журнал событий видимости.
6. Windows 11 Pro x64, версия 10.0.26200; около 127.1 GiB RAM, 32 логических процессора, около 74.5 GiB свободно на C: во время осмотра.
7. Проверены команды: Python 3.12.7, Git 2.52.0.windows.1, Java/Javac 23.0.2. Через Python Launcher также зарегистрированы Python 3.12, 3.11 и 2.7. Для проекта выбран Python 3.12.
8. `.NET` runtime 6.0.36 найден; `dotnet --list-sdks` вернул пустой список. Наличие SDK для C# не подтверждено.
9. Wireshark/TShark 4.0.6 установлен в `C:\Program Files\Wireshark`; TShark проверен командой `--version`. В реестре есть Npcap 1.75. Работоспособность захвата и драйвера не проверялась.
10. Найдены `wpr`, `wpa`, `logman`, VS Code; в реестре есть Visual Studio Community 2019. Установленные компоненты компилятора C++ не проверялись.
11. Maven, Gradle, Docker не найдены в PATH; стандартный путь Docker Desktop отсутствует. `wsl --list --quiet` сообщил, что WSL не установлен.
12. На момент первичного снимка среди проверяемых имён процессов найден только Code; AsteriosGame, Java и серверы БД из проверенного списка не наблюдались. Это не доказательство отсутствия всех возможных серверных процессов.

Источник перечисленного: environment-inventory.json (`docs/environment-inventory.json`), созданный из локальных команд PowerShell и ответов инструментов.

## Что ещё не установлено

В последующей записи начальный ProtocolVersion содержит значение 448. Это не устанавливает совместимость клиента с собственным Interlude-сервером. Наличие исходной аномалии и её причина не установлены. Поведение оригинального сервера NCSoft не исследовано. Серверные механизмы KnownList и видимости L2J/aCis/Mobius пока не проверены.

Для серверной лаборатории нужны конкретный репозиторий и commit, подходящий тестовый клиент, локальный сервер с БД и персонажи A/B/C. Для первого синтетического прототипа этих компонентов не требуется.

## Проверка штатного входа

После первичной инвентаризации пользователь отдельно поручил проверить предоставленные учётные данные. 2026-11-21 вход выполнен через обычную форму клиента и экран пользовательского соглашения. Получен список серверов Prime, Medea, Asterios, Hunter; выбран Prime, после подключения появился экран `Select Character` с заголовком окна `Asterios Prime`. На Prime персонажей нет; создание персонажа и вход в игровой мир не выполнялись. Клиент оставлен на экране выбора персонажа.

Подтверждены авторизация и подключение к Prime в момент проверки. Вход в игровой мир и подключение к остальным серверам не проверялись. Это штатное подключение не является проверкой гипотез о рассинхронизации. Пароль в проект не записан. Снимок результата: reports/login-prime.png (`reports/login-prime.png`).

## Последующая проверка X501 и сетевого обмена

Пользователь создал X501; в следующем сеансе персонаж наблюдался в игровом мире Prime. Выполнены две пассивные записи выбранного серверного соединения, включая новое подключение после согласованного перезахода. Эти наблюдения дополняют первоначальную проверку пустого списка персонажей.

Характеристики записей и первоначальные проверки: [packet-analysis.md](packet-analysis.md). Последующая офлайн-расшифровка успешно завершена в обоих направлениях: 1879 серверных и 125 клиентских прикладных сообщений; подтверждены вход и мировой Object ID X501. [Проверки и команды повторения](decryption-progress.md).

Продолжение смыслового анализа: построена временная шкала 2004 сообщений, выделены 100 NPC и семь предметов. Все 22 Action направлены к ранее описанным и ещё не удалённым целям; все 74 DeleteObject относятся к ранее описанным объектам. Зафиксированы 19 обновлений десяти NPC до EnterWorld и последующих NpcInfo. Пакетов с эталонным opcode CharInfo и удаления собственного объекта X501 нет. Эти факты не устанавливают фактическую отрисовку или состояние KnownList. [Полный отчёт и источники полей](packet-lifecycle.md).

## Статическое исследование через REA

По отдельному поручению пользователя REA проверила импорты и экспорты AsteriosGame.exe, Engine.dll, IpDrv.dll и экспорты 32-битной системной WSOCK32.dll. Найдены экспортные имена клиентских сетевых компонентов и обработчиков OnCharInfo, OnUserInfo, OnDeleteUser. Вызовы этих функций при работе X501 и соответствие сетевым opcode не доказаны. Подробности, Evidence, схема начального обмена и индекс сообщений: [rea-network-structure.md](rea-network-structure.md).

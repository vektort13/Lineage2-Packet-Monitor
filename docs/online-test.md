# Онлайн-проверка расшифровки Prime

2026-11-21. Проверка выполнена на свежем трафике текущего соединения X501 с Prime. Игра оставалась подключена; ввод, перезаход и изменение процесса не выполнялись. Это захват работающего соединения с последующей проверкой расшифровки, а не постоянно работающий монитор.

## Результат

За интервал между двумя наблюдениями состояния клиента расшифрованы:

- **84 серверных блока**: счётчик `71874 → 71958`.
- **13 клиентских пакетов**: счётчик `9335 → 9348`.

Конечные 16-байтовые ключи обоих направлений точно совпали с состоянием работающего клиента. Для каждого клиентского тела исходный шифротекст побайтно воспроизведён сохранённой оригинальной функцией в изолированном эмуляторе. Конечное состояние младших 16 бит шифрования длины также совпало. В эмуляторе сетевые функции не вызываются; при повторной расшифровке доступ к игре не требуется.

69 серверных блоков содержат обычные сообщения, в том числе 23 ValidateLocation, 18 MoveToLocation, три DeleteObject. Среди них есть сообщение с мировым Object ID X501 `270128929`. Клиентские пакеты: 11 RequestBypassToServer, один MoveBackwardToLocation и один ValidateLocation; названия взяты из эталонной таблицы NetPro 448.

**15 серверных блоков расшифрованы до маркера `8D` и сжатого содержимого, но ещё не распакованы.** Захват начат посреди соединения; предшествующая история raw DEFLATE отсутствует. Начальный словарь не подставлялся. Число внутренних сообщений этих блоков в результат 69 не включено.

Это подтверждает работу преобразования свежих пакетов при больших текущих значениях счётчиков, помимо ранее полностью разобранной записи с начала подключения. Видимость моделей и состояние KnownList этим тестом не измерялись.

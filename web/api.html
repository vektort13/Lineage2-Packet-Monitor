L2 Packet Monitor API

JSON UTF-8. GET /api/info возвращает token для заголовка X-Monitor-Token в POST. Адрес: 127.0.0.1:8765.

Фильтры

/api/packets?categories=movement,inventory&types=server:21,client:B0&limit=250

Категории и типы работают совместно. Отсутствующий параметр означает все; пустой categories= или types= скрывает все. Следующий запрос использует after=cursor из ответа. Лимит 1–1000.

HEX ↔ текст

{"mode":"hex-to-text","hex":"58 35 30 31 00","encoding":"utf-8"}
{"mode":"text-to-hex","text":"X501\\0","encoding":"utf-16le"}

Кодировки: utf-8, utf-16le, cp1251, latin-1. Обратимые escape-последовательности: \xNN — байт, \uNNNN — символ, \0 / \n / \r / \t / \\.

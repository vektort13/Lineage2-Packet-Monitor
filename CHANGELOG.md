# Changelog / Изменения

## 1.0.0 — 2026-11-25

First GitHub release / первый релиз на GitHub.

- Native Windows desktop application with nine tabs, Russian/English and dark/light themes.
- Auto, network, client plaintext and server bridge sources; two saved client build profiles.
- Packet filtering, HEX/text copy editor, outgoing packet queues and JSON exports.
- Character panel with CP/HP/MP recovery, inventory, skills, nearby items and additional actions.
- Complete client database, original icon archive and Java/Python server SDK.
- Portable build scripts, pinned dependencies, bilingual guides and screenshot gallery.

Нативное окно с девятью вкладками, двумя языками и темами; источники пакетов, профили, редактор, очереди, персонаж, инвентарь, скиллы, база клиента и SDK. Добавлены переносимая сборка, руководства и галерея.
